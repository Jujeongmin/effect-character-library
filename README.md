## Character Library (준비 중)

이펙트와 별개인 캐릭터 리소스 라이브러리. 링크와 매니페스트를 이펙트와
분리해 뒀고, 저장소는 하나로 합쳐져 있습니다.

**https://jujeongmin.github.io/effect-character-library/characters/**

분류는 인간형(`humanoid`) / 몬스터형(`monster`). 아직 리소스가 들어오기 전
틀만 있는 상태 — 항목 추가 방법은 [CHARACTERS.md](CHARACTERS.md) 참고.
