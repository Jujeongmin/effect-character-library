## Character Library

이펙트와 별개인 캐릭터 리소스 라이브러리. 링크와 매니페스트를 이펙트와
분리해 뒀고, 저장소는 하나로 합쳐져 있습니다.

**https://jujeongmin.github.io/effect-character-library/characters/**

인간형 69 · 야수형 54 · 동물형 7 · 몬스터형 42, 총 172개 캐릭터(그림 299장,
일부는 색상 스킨·표정을 여러 모습으로 묶음 — 카드 오른쪽 아래 "N개" 표시로
클릭 전에 알 수 있습니다. 애니메이션 아니고 정지 그림 여러 장 중 고르는
것입니다). 분류는 원본 폴더가 아니라 생김새 기준(사람 체형/짐승 몸/평범한
동물/그 외 몬스터), 캐릭터 묶음은 색상만 다른지 콘셉이 다른지 기준 —
자세한 건 [CHARACTERS.md](CHARACTERS.md).

effects 페이지처럼 상단의 **AI에 연결하기**를 누르면 이 라이브러리를 프로젝트에
붙이는 프롬프트가 복사됩니다 — 쓰는 AI 도구에 한 번만 붙여넣으면 그 뒤로는
id(+ 모습이 여러 개면 그 이름)만 말하면 됩니다.

id·이름은 원본 자료에 이름이 없는 항목(대부분 몬스터, 일부 캐릭터)은
생김새 보고 대충 지은 것입니다 — 다른 프로젝트에서 가져다 쓸 때 원하는
이름으로 다시 붙이면 됩니다. `note` 필드에 "이름 미상"이라고 표시해 뒀습니다.

항목 추가·스키마는 [CHARACTERS.md](CHARACTERS.md) 참고.
